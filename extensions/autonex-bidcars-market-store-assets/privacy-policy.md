# Auto Nex – BidCars Market Analysis Privacy Policy

Last updated: October 10, 2026

The extension reads public vehicle and finalized-auction information displayed on BidCars pages opened by the user. This may include lot number, VIN, vehicle specifications, auction house, location, mileage and final bid.

The extension stores this information locally in Chrome for up to 30 days. When the user explicitly configures an Auto Nex collector key, the extension sends the public vehicle records to the user's configured Auto Nex API for storage and analysis. It does not collect passwords, payment-card information, private messages, browsing history outside supported BidCars pages or unrelated personal information.

The collector key is stored using Chrome synchronized extension storage. It is used only to authenticate record synchronization with the configured Auto Nex API. Auto Nex API requests are also used to calculate transport and customs estimates.

Users can remove locally stored vehicle records with the “30 günü sıfırla” button and can uninstall the extension at any time. Server-side records are controlled by the operator of the configured Auto Nex deployment.

The extension is not affiliated with BidCars, Copart or IAAI. For privacy questions, use the contact information published by the Auto Nex operator on the Auto Nex website.
