# Chrome Web Store listing

## Name
Auto Nex – BidCars Final Price Calculator

## Short description
Calculate BidCars auction fee, US–Baku transport, Azerbaijan customs and final AZN cost directly on a lot page.

## Detailed description
The extension reads the selected bid, auction house, location, year, engine and fuel type from BidCars. It combines the vehicle price with the auction fee, Auto Nex transport tariff and Azerbaijan customs estimate, then shows the final amount in AZN. Copart and IAAI tariffs are handled separately. Hybrid, diesel, electric and gasoline vehicles use their corresponding customs type.

This extension is an independent calculator and is not affiliated with BidCars, Copart, IAAI or Azerbaijan customs authorities. Results are estimates and must be verified before purchase.
